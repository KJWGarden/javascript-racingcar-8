# javascript-racingcar-precourse
## 사용자에게 이름 문자열 입력받기
- 프로그램에 돌아갈 이름 문자열을 받는다
- 해당 문자열은 구분자(,) 를 기준으로 나뉜다
- 나뉜 문자열을 이름으로 저장된다 (각 이름의 글자수는 5자 이하만 가능)
## 사용자에게 반복횟수 입력받기
- 사용자에게 반복횟수를 입력 받는다
- 입력 받은 값만큼 각 자동차 이동을 반복한다.
## 자동차 이동하기
- 각 자동차를 움직이는 함수를 구현한다
- 해당 함수는 0 에서 9 사이에서 무작위 숫자를 구한다.
- 무작위의 값이 4보다 크면 자동차는 전진한다.
- 그외의 값은 정지한다.
## 우승자 출력하기
- 반복 횟수가 끝난 후 우승자를 출력한다.
- 공동 1등으로 인해 우승자가 여러명일 때 (,) 구분하여 출력해준다.
## 예외처리
- 입력을 잘못했을 때 ERROR 발생시키기
- ERROR 발생시, ERROR 메세지 출력하기
- ERROR 메세지 출력후, 프로그램 종료시키기
